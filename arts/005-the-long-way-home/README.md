# the long way home

A painting that paints itself. About 50,000 brush marks, nine seconds, no images.

**Click it** to paint another one. Every version has different clouds and different marks, and it alternates between golden hour and blue hour.

## what you're looking at

There are two pictures. The one you never see is a crude, flat drawing of the scene: gradients, blobs and polygons, like a paper cut-out. The one you do see is made only of brush marks, and every mark asks the hidden picture one question: *what colour is it here?*

Three things make it read as paint instead of a filter:

- **Big to small.** The first pass covers everything in fat marks. The last pass uses tiny ones, and only where something changes, so the sky stays broad and the house gets crisp.
- **The marks have a direction.** Sky is hatched on one slant. The wheat runs to a single vanishing point. Leaves go every way. Walls are square. Take the directions away and it turns to noise.
- **A mark is a bundle.** Each one is five or ten thin lines side by side, like bristles. That is where the pastel texture comes from.

The poles, wires, cyclist, birds and poppies are painted last, by position, with the same brush.

## things worth stealing from the prompt

- **"Draw a plain flat version off-screen first."** This is the whole trick. Asking an agent to "paint a landscape with strokes" in one go gets mush; separating *what the picture is* from *how it is painted* gets both right.
- **Give the order of work.** A numbered list in the order a painter would do it. The agent builds it in that order too.
- **Say where detail must not go.** "Only paint where the picture changes, so flat areas stay calm."
- **Name the light once.** "Sun low on the left: warm lit side, long violet shadow pointing right." Every object then agrees.
